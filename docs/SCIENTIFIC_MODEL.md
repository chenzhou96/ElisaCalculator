# 科学模型与结果解释

## 两种任务

- 曲线比较：拟合各组响应曲线，报告中点、斜率、拟合质量，并以指定参比组的 1X、10X 等赋值换算相对倍数
- 标准曲线定量：拟合已知标准，在有效区间内反算未知样本的浓度或相对剂量，最后乘以该样本的稀释倍数

本工具用于科研数据分析，不替代实验方法验证，也不将拟合收敛视为定量已被验证。

## X 输入必须有明确含义

1. 原始浓度：内部使用 log10(浓度) 拟合，因此浓度必须为正；单位由用户填写
2. log10 浓度：输入已经取 log10，不再重复变换；负数和零均可合法
3. 稀释序号：如 1–8，默认序号越大、稀释越多。若稀释倍数为 f，起始序号为 s0，则 log10 剂量 = log10(c0) − (s−s0) × log10(f)。反向梯度使用相反符号

如果不知道 c0，令起始相对剂量为 1，仅用于无量纲剂量与倍数分析。此时不得把输出标成 ng/mL 等绝对浓度。

## 4PL 与中点

使用模型 y = D + (A−D) / (1 + 10^[B(x−C)])，x 为内部 log10 剂量。

- C 是 logEC50。EC50 剂量为 10^C，绝不是直接将 C 当浓度
- 稀释序号模式还可把 C 逆变换为 EC50 序号
- 中点为两个拟合平台的均值，不一定是原始吸光度 0.5
- 本版本规范化为 A=下平台、D=上平台且 D>A；B>0 表示随剂量增大响应增大，B<0 表示相反方向。旧版本的固定 A“上限”、D“下限”标签已纠正

## 参比倍数与原液相对强度

对相同稀释方案、相同起始相对剂量的各组：

表观相对原液强度 = 参比赋值 × EC50剂量(参比) / EC50剂量(待测)

在序号越大稀释越多的模式下，可写成：参比赋值 × f^(待测中点序号 − 参比中点序号)。因此同样响应需要更高稀释的原液更强。例如 f=2，中点比参比晚两级，对应 4 倍；参比赋值 10X 时为 40X。

若输入的是绝对浓度，EC50 比值只表达按相同浓度比较的半效浓度比，不能在不知道各组原液起始浓度时自动称为原液强度。不同斜率、不同平台或不同响应定义下的中点比值，也不能替代整个曲线的恒定效价比。

## 拟合与质量控制

- 独立拟合允许各组平台不同；共享平台拟合仅在实验上合理时选择
- 无权重最小二乘是当前默认假设。异方差明显时须评估误差结构，不能只看 R²
- 置信区间基于残差雅可比矩阵的 SVD 协方差和 Student-t 局部近似，包含共享拟合中参比协方差交叉项；不能修复平台覆盖不足或参数不可辨识。边界命中、秩不足或严重病态时不提供可信区间、比较倍数或未知浓度
- 非有限值、无效浓度、数据点不足、弱平台覆盖、差的拟合质量、越界中点等均应审阅
- 复孔、空白扣除、未知样本稀释倍数必须显式配置；导出记录保留原始输入和处理后的数据

## 反算范围

反算只在选定标准曲线的响应方向和测量区间内解释。落在渐近平台外、超出已测标准范围、非正样本稀释倍数或标准不可辨识时，不应静默给出可信浓度。结果表应同时显示样本响应、处理过程、稀释前后浓度和警告。

## 可追溯性

导出 CSV 是便于查看的摘要；Analysis_Record.json 是完整分析记录，包含配置、结果、原始/处理数据和导出警告。图预览不依赖磁盘导出。修改输入或设置后，上一次结果必须失效或明确标为过期。

## 0.3 桌面工作流与参比重归一

当前桌面新分析只支持 96 孔板连续稀释组比较，不提供独立表格或标准反算入口。上述历史标准定量公式仍保留供旧科学接口和审计回归理解，旧记录不会自动改义。

结果页仅改变参比组或正参比赋值时，使用初次计算保存的未舍入组参数、剂量坐标、全 midpoint 协方差及比较前警告重新运行比较层；不调用 least_squares、不解析原始输入、不重画图。多次切换从同一原始拟合上下文出发，不从已显示的 X 反推。以新参比为分母重新检查单位、剂量域、响应方向、可辨识性和参比质量，并重算协方差中的交叉项；不能简单缩放旧置信区间。失败拟合不能成为参比。缺少上下文的历史结果须重新分析才能改参比。
