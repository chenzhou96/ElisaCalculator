# 96 孔板工作台

本功能把原始板读数明确映射为 Python 引擎的输入，使用 4PL 拟合与明确剂量标尺下的中点比较。所有示例都是合成软件真值，不是实验结果。

## 导入与选孔

从 Excel 复制 8 行 × 12 列，或从指定起始孔导入一个小矩形。A–H 是行，1–12 是列；孔位身份固定为 A1…H12。预览显示尺寸、缺失、非法和覆盖计数。保留内部空单元和尾空列，空值不转换为零，数字 0 是有效读数。尺寸越界、行长不一致不导入；不自动转置。CSV/TSV 文件使用明确分隔符和 UTF-8，限定为一个板的文本（1 MB 内），不直接读取二进制 Excel 文件。

非法读数默认阻止导入；明确勾选后可以一次性保留原文和坐标，再修正或排除。覆盖现有读数须确认，且保留孔位标记。取消和失败不部分写入。

单击选择一孔，⌘ / Ctrl 单击多选，Shift 单击矩形扩选，拖动框选；列号选择整列，行号选择整行。箭头移动焦点，Shift + 箭头扩选。单孔可编辑原始 OD 草稿，空输入仍是缺失；点击“应用到选中孔”才保存。

## 数值与公式输入

所有数值输入框支持数字、科学计数法、括号和四则运算，例如 `=1/20` 得到 `0.05`、`=(2+3)*4` 得到 `20`。按 Enter 或离开输入框后显示结果；不完整表达式、除零及非有限结果保留输入并提示错误。表达式只解析数字与运算符，不执行代码。原有正值、稀释倍数和有限值要求仍适用。

孔板读数及导入的 Excel/CSV/TSV 文本支持公式，导入原文保留在输入审计中。

## 标记与梯度

新分析明确选择比较曲线、空白、排除或未分配。待测样品按连续稀释比较组处理，未知起始浓度不走标准反算。选中已标记孔立即读取既有设置，选中未分配孔恢复项目默认值；多选不同设置显示混合状态，需明确统一设置。选择、修改草稿和取消不写入板图；只有“应用到选中孔”写入选中孔，已有标记覆盖须确认。选择已有梯度中间孔不会把该孔剂量错误当作梯度起点，局部应用不会重启整组梯度。

每组可设置自己的起始量、2–10 倍梯度、递增/递减和行/列方向。沿列从上到下或沿行从左到右确定顺序，与点击顺序无关；重复列/行分别从起始量重启。例如绝对浓度起始 128、二倍递减，两列均产生 128、64、32、16、8、4、2、1。

缺孔有两种明确约定：“按物理位置保留间隔”保留缺孔原本的稀释级数；“仅选中孔连续编号”使选中孔连续。应用前预览列出各孔剂量。板图同组同色，浓度高的孔色深，同时显示孔位、组名、类型、OD 和剂量。旧未知孔仍显示原 DF，直到明确重标记。

撤销/重做是原子操作，保留板图和当时的分析约定；⌘ / Ctrl + Z、Shift + Z / Y 可操作。选择与草稿变化不使结果失效；已应用读数、标记、剂量、空白、复孔、拟合模式和撤销/重做使旧结果失效。仅修改参比组或赋值从已有未舍入拟合重新归一，不重拟合。旧版本异步响应不能覆盖较新输入。

## 剂量、参比与标准

“无量纲剂量”允许任意有限正数，包括 20、128 等大于 1 的起始值；1 不代表原液，0.5 不代表二分之一原液。各组按用户确认的同一剂量标尺比较，不推断物理浓度。已有明确绝对浓度时选择“已知绝对浓度”并填写单位。

无量纲模式把已确认剂量 q 编码为 X = 1 − log2(q)，用已有引擎的 dilution_step、factor=2、first_step=1 转换回 log10(q)。这只是无损坐标编码，不把实际 3/5/10 倍梯度改成二倍梯度；原始梯度、孔位和剂量仍保存在板图和映射中。不同组剂量网格按并集生成，保留各组没有测量的空格，不插值、不伪造数据。

曲线比较必须明确选参比和正参比赋值：在相同无量纲剂量标尺下，中点相对值 X = 参比赋值 × EC50(参比) / EC50(待测)。参比赋值 10X、待测 EC50 为参比四分之一时输出 40X，结果字段为 Normalized_midpoint_X，不作为原液强度。绝对浓度模式没有原液浓度，保留 EC50 比值，禁止编造原液 X。

结果页可直接修改成功拟合的参比及赋值，使用保存的原始拟合、全协方差与比较前警告重建归一值和条件置信区间；不重复乘已有 X。参比 10X / 待测 40X，改为待测 7X 后参比 1.75X。失败拟合不出现在参比选择中；旧快照缺少无重拟合上下文时不伪造归一，明确提示重新分析。

X 是条件性的表观中点比较。拟合成功不证明曲线平行或不同响应水平下恒定效价；非平行斜率、参比质量、平台、范围和可辨识性警告必须结合曲线审阅。相反响应方向或不能拟合/辨识的参比不能给出可用比值。

## 空白、复孔与映射检查

空白不进入拟合，作用域须明确选择：不扣空白、全板有效空白均值或同名组空白均值。同组模式中空白孔组名指定比较曲线作用对象；缺少同名空白阻止计算，不回退全板。每个拟合孔只扣一次，原始 OD 保留，负处理值保留并提示，不裁零。引擎收到已校正的规范输入并明确设置 blank_mode=none，避免重复扣除。

重复列显式映射到同组，每个孔保留独立来源。“逐孔拟合”让每个有效观测等权；“每剂量均值”先取每组每剂量均值再等权拟合剂量均值，不按复孔数加权。技术复孔不等于独立实验。合法的含双引号组名在规范 TSV 中明确转义，保留原名和参比身份。

“检查孔位映射”逐行显示孔位、类型、组、原始 OD、剂量/DF、空白、处理 OD、表格列和行。未分配但有读数、已分配缺失/非法读数、无效剂量、每组不足四个不同剂量、无参比引用和缺空白均阻止计算。直接点击“运行分析”会自动检查并计算；输入有问题时会跳转到对应页面或面板，选中有问题的孔并高亮输入框。“检查孔位映射”及“解析预览”是可选入口，可以先保存未完成板图。

## 日间与夜间配色

右上角按钮和“视图 → 夜间模式”可切换配色；本机保存选择，重启后恢复。配色切换保留输入和结果，不触发重新计算。

## 记录与兼容

“保存记录”使用 elisa-analysis/2，保存全部 96 孔、类型、组、剂量、原始字符串、完整梯度、空白/复孔约定、配置、未舍入拟合、结果、预览及参比设置。恢复 v2 直接显示“历史结果快照”，不会调用 Python 重算；重新分析有独立状态。只恢复结构校验通过的内容。

桌面自动历史与上次会话保存在应用数据目录，通过临时文件、同步与原子替换确认写入，不放在临时导出缓存。保存失败明确显示，不丢弃当前窗口内容；关闭窗口前等待持久保存。浏览器开发版使用严格 IndexedDB 事务；重要记录请独立另存 JSON。

旧 elisa-analysis/1 仅恢复输入，不制造拟合。旧表格、标准反算配置、未知样品及 DF 完整保留并提示只读兼容；不会自动转成孔板。旧标准/未知孔位仍保留原类型，明确重新标记后才能比较。新实验只使用孔板右侧“分析约定”；不再保留重复左侧设置、独立表格或新标准反算入口。

磁盘科学导出 Analysis_Record.json 保存完整审计与孔位映射，是审计格式；界面 v2 JSON 是恢复格式。图像预览不依赖磁盘导出，仅参比修改不再把旧导出路径称为新结果已导出。
