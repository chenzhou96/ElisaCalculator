# 96 孔板工作台

本功能把原始板读数明确映射为已有 Python 引擎的输入，不改变 4PL 拟合、反算、比较、质量控制或导出算法。所有示例都是合成软件真值，不是实验结果。

## 导入与选孔

从 Excel 复制 8 行 × 12 列，或从指定起始孔导入一个小矩形。A–H 是行，1–12 是列；孔位身份固定为 A1…H12。预览显示尺寸、缺失、非法和覆盖计数。保留内部空单元和尾空列，空值不转换为零，数字 0 是有效读数。尺寸越界、行长不一致不导入；不自动转置。CSV/TSV 文件使用明确分隔符和 UTF-8，限定为一个板的文本（1 MB 内），不直接读取二进制 Excel 文件。

非法读数默认阻止导入；明确勾选后可以一次性保留原文和坐标，再修正或排除。覆盖现有读数须确认，且保留孔位标记。取消和失败不部分写入。

单击选择一孔，⌘ / Ctrl 单击多选，Shift 单击矩形扩选，拖动框选；列号选择整列，行号选择整行。箭头移动焦点，Shift + 箭头扩选。单孔可编辑原始 OD，空输入仍是缺失。

## 标记与梯度

明确选择比较曲线、标准曲线、未知样品、空白、排除或未分配。组名定义比较对象或样品；排除不擦除原读数、组别或剂量。修改已有标记须确认，只作用于选中孔。

每组可设置自己的起始量、2–10 倍梯度、递增/递减和行/列方向。沿列从上到下或沿行从左到右确定顺序，与点击顺序无关；重复列/行分别从起始量重启。例如绝对浓度起始 128、二倍递减，两列均产生 128、64、32、16、8、4、2、1。

缺孔有两种明确约定：“按物理位置保留间隔”保留缺孔原本的稀释级数；“仅选中孔连续编号”使选中孔连续。应用前预览列出各孔剂量。板图同组同色，浓度高的孔色深，同时显示孔位、类型、OD 和剂量；未知孔显示 DF。

撤销/重做是原子操作，保留板图和当时的分析约定；⌘ / Ctrl + Z、Shift + Z / Y 可操作。选择变化不使结果失效，读数、标记、分析约定、撤销/重做与输入视图切换均使旧结果失效，旧版本异步响应不能恢复结果。

## 剂量、参比与标准

“相对原液分数”明确规定每组的 1 表示该组原液，0.5 表示二分之一原液；相对模式的已分配剂量须在 (0,1]。这不是任意名义单位，也不产生 ng/mL。默认起始 1、二倍递减适合常见原液连续稀释。需要 128…1 等实际浓度时选择“已知绝对浓度”并填写单位。

相对模式把已确认分数 q 编码为 X = 1 − log2(q)，用已有引擎的 dilution_step、factor=2、first_step=1 转换回 log10(q)。这只是无损坐标编码，不把实际 3/5/10 倍梯度改成二倍梯度；原始梯度、孔位和剂量仍保存在板图和映射中。不同组剂量网格按并集生成，保留各组没有测量的空格，不插值、不伪造数据。

曲线比较必须明确选参比和正参比赋值：在相同原液分数约定下，原液中点强度 X = 参比赋值 × EC50(参比) / EC50(待测)。参比 10X、待测中点原液分数为参比四分之一时输出 40X。绝对浓度模式没有原液浓度，保留 EC50 比值，禁止编造原液 X。

标准反算必须使用明确绝对浓度、单位和标准曲线引用；未知孔不会进入拟合表。未知同名复孔先作为 OD 复孔反算，校正倍数至少 1 且同名孔一致；稀释校正最后乘一次。例如测定液 12 × DF5 = 原样 60；记录恢复后 4 × DF10 = 40，不能再次乘成 400。默认超范围不输出浓度；明确允许外推时保留警告。

X 是条件性的表观中点比较。拟合成功不证明曲线平行或不同响应水平下恒定效价；非平行斜率、参比质量、平台、范围和可辨识性警告必须结合曲线审阅。相反响应方向或不能拟合/辨识的参比不能给出可用比值。

## 空白、复孔与映射检查

空白不进入拟合，作用域须明确选择：不扣空白、全板有效空白均值或同名组空白均值。同组模式中空白孔组名指定作用对象（包括未知样品名）；缺少同名空白阻止计算，不回退全板。每个拟合/未知孔只扣一次，原始 OD 保留，负处理值保留并提示，不裁零。引擎收到已校正的规范输入并明确设置 blank_mode=none，避免重复扣除。

重复列显式映射到同组，每个孔保留独立来源。“逐孔拟合”让每个有效观测等权；“每剂量均值”先取每组每剂量均值再等权拟合剂量均值，不按复孔数加权。技术复孔不等于独立实验。合法的含双引号组名在规范 TSV 中明确转义，保留原名和参比身份。

“检查孔位映射”逐行显示孔位、类型、组、原始 OD、剂量/DF、空白、处理 OD、表格列和行。未分配但有读数、已分配缺失/非法读数、无效剂量、每组不足四个不同剂量、无参比/标准引用和缺空白均阻止确认。可以先保存未完成板图，但运行前必须确认映射并解析。

## 记录与输入视图

“保存记录”使用原有 elisa-analysis/1 格式的兼容扩展，保存全部 96 孔、选择、梯度、类型、组、剂量、原始字符串、排除、空白/复孔约定、未知 DF、分析配置和当前结果。恢复只恢复输入，必须重新解析/计算，不把旧结果当作当前结果。旧版纯表格记录仍可恢复。撤销历史不写入便携记录。

“表格输入”保留原有独立原始文本；切换视图不擦除板图或文本，不猜测双向转换。板图和表格分别保留自己的参比/赋值、工作流、拟合和标准反算约定；切换、撤销与保存恢复不会互相覆盖。板图解析也不覆盖表格独立选择的 X 轴列。分析设置面板按当前输入视图显示，两种工作流继续使用同一科学引擎。

磁盘导出的 Analysis_Record.json 在 report.metadata.plate_mapping 中保存原始完整板图、逐孔映射、空白/复孔语义及坐标编码；这是科学审计格式，不是界面恢复文件。界面保存 JSON 仍是可恢复记录。图像预览不依赖磁盘导出。

## 开发验证

沿用现有依赖与安全配置，不需要为孔板功能新增软件包。

```sh
python -m unittest discover -s tests -v
cd desktop-ui
npm run build
npm run lint
npm test
npm run test:integration
# 非默认 Python 可显式设置 ELISA_PYTHON；默认使用 PATH 中的 python
npm run test:plate-science
# 使用已安装的 Chromium；chromiumSandbox 保持 true
npm run test:e2e
```

Mac 原生调试构建使用现有 tauri.macos.conf.json。当前 .app 依赖系统 Python；Windows 安装包和干净系统发行测试须单独验收，Mac/浏览器结果不代替它们。
